Quiz Application with Timer

This quiz application allows users to answer multiple-choice questions within a limited time. It includes quiz rules, countdown timer, answer validation, score calculation and a responsive layout that works on mobile, tablet and desktop screens.

Timer

Each question has a countdown timer.

Feedback

Answers show correct or wrong instantly.

Responsive

The design works on all screen sizes.

Some Rules of this Quiz
1. You will have only 15 seconds per each question.
2. Once you select your answer, it cannot be undone.
3. You cannot select any option once time goes off.
4. You can exit the quiz using the close button.
5. You will get points based on your correct answers.
